# Quiet Cosmos — channel identity

Upload-ready files are in `out/`. To regenerate them (for example, after changing a color):

```bash
python branding/make_branding.py
```

| File | Where it goes in YouTube Studio › Customisation › Profile |
|---|---|
| `out/profile_800.png` | **Picture** |
| `out/banner_2560x1440.png` | **Banner image** (all text is inside the 1546×423 safe area) |
| `out/watermark_150.png` | **Video watermark** → display time: *Entire video* |

## Palette and type

| Role | Color |
|---|---|
| Night sky (background) | `#0B0F1A` |
| Unlit planet | `#141B2E` |
| Starlight (main text) | `#E8E4D8` |
| Secondary text | `#C9C4B6` |
| Accent (orbit, schedule) | `#E9B872` |

Display font: **Cormorant Garamond** Light. Body font: **Jost** Light and Regular. Both use the SIL Open Font License, and copies are in `fonts/`.
